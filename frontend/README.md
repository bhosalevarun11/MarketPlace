# LUMA – Premium Marketplace Prototype

An elegant, fully frontend educational adult marketplace prototype inspired by Amazon and luxury discovery experiences.

## 🌟 Key Features

1. **Immediate Profile Discovery on Homepage**:
   - Opens immediately into the curated profile cards grid with 24 fictional adult profiles (ages 21+).
   - Responsive grid: **4 profiles per row on desktop**, **2 per row on mobile**.
   - No huge hero banners blocking cards.

2. **Zero Backend Required**:
   - Runs directly in any web browser without Python, FastAPI, Node, or database dependencies.
   - Simply double-click `index.html` to open!

3. **Pure Client-Side State Management**:
   - Fictional profiles, ratings, and reviews loaded from `js/data.js`.
   - Simulated demonstration bookings and favorite bookmarks stored in your browser's `localStorage`.

4. **Special Marathi Branding**:
   - Tagline: *"काढा तुमचा डांडा, झवा आमच्या रांडा"* featured beneath the LUMA logo and in the footer with bold Devanagari typography.

5. **Advanced Instant Filtering & Sorting**:
   - Real-time keyword search across names, cities, categories, and bios.
   - City selector (Mumbai, Delhi, Pune, Bengaluru, Goa, Jaipur, Kolkata).
   - 4 Illustrative Price Tiers:
     - **Essential**: ₹999 – ₹1,999
     - **Premium**: ₹2,000 – ₹4,999
     - **Elite**: ₹5,000 – ₹9,999
     - **Luxury**: ₹10,000 – ₹19,999
   - Category chips (Companion, Entertainer, Instructor).
   - Dynamic sorting (Lowest Price, Highest Price, Rating, Newest, Most Popular).

6. **Interactive Demo Booking Workflow**:
   - Click "Book Now" on any card or inside the profile details page.
   - Pick demonstration date and time slot.
   - Enter mock guest details and submit.
   - Instant confirmation screen with Booking ID (`LUMA-BK-XXXX`).
   - View or cancel bookings anytime in the "My Bookings" modal.
